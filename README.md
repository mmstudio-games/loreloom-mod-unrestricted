# Loreloom Unrestricted

一个面向 Loreloom 的叙事取向扩展。它通过补充叙述者与 NPC 提示词，减少对黑暗、残酷、成人、争议或令人不适题材的自动回避与淡化，让角色选择和故事后果更直接地遵循既有世界事实。

## 功能

- 忠实响应玩家明确选择的叙事方向，不额外设置题材或冲突强度方面的创作禁区。
- 保留 NPC 的自主性；角色可以拒绝、隐瞒、欺骗、犯错、改变立场或采取会产生严重后果的行动。
- 避免用叙事外说教、讨好玩家或维护预定剧情来代替角色自身判断。
- 强调自然、直接、具体的表达，同时保持角色认知边界。

## 作用边界

本 Mod 只调整叙事提示，不会修改 Loreloom 的世界状态机制。已经发生的事实仍以已提交的 ECS 状态和 Tool 结果为准；角色愿望、推测或尚未提交的行动不会因此自动成为世界事实。

它也不会赋予角色额外知识、改变工具权限，或覆盖宿主应用及模型本身的安全规则。

## 安装与使用

1. 下载或克隆本仓库。
2. 通过 Loreloom 支持的本地 Mod 加载方式添加本目录。
3. 启用 Mod，并确认加载器识别到 `games.loreloom.unrestricted`。

具体入口可能随 Loreloom 版本变化，请以当前版本的 Mod 管理界面或加载器说明为准。

## 项目结构

```text
.
├── mod.toml              # Mod 清单、兼容版本与提示词入口
└── prompts
    ├── narrator.md       # 叙述者提示词
    └── npc.md            # NPC 提示词
```

## 自定义

可以直接编辑 `prompts/narrator.md` 和 `prompts/npc.md` 调整叙事取向。修改发布内容时，请同步维护 `mod.toml` 中的版本号和 `content_hash`，以符合 Loreloom 的内容校验要求。
